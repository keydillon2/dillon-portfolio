# Security policy

This repository runs dillonkey.com, a personal portfolio site.

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- Use GitHub's **"Report a vulnerability"** button on this repository's Security tab, or
- Email dillon.key@gmail.com with "Security" in the subject.

Include what you found, how to reproduce it, and any impact you see. You'll get a reply within a week.

## Scope

In scope: the site's code in this repository, including the chat assistant (`/api/chat`) and the questions page.
Out of scope: Vercel, Sanity, and Groq infrastructure (report those to the providers).
